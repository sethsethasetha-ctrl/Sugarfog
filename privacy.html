Privacy Policy

Glimbrule: Sugar Siege · Effective date: October 19, 2026

Scope

This policy applies to Glimbrule: Sugar Siege version 1.0 (build 1), published by jiangfuqin. The game is designed for offline play on iPhone and iPad.

Information the game stores

The game stores local gameplay progress and settings on your device, such as campaign progress, an active run, audio preferences, and graphics preferences. This information is used only to resume and configure the game. It is not sent to a server by the current build.

Information the game does not collect

The current build has no account system, advertising SDK, analytics SDK, tracking SDK, or social login. It does not request access to contacts, photos, camera, microphone, location, or health data. It does not use the AppTrackingTransparency framework and does not request an ATT authorization prompt because the game does not track users or access IDFA.

Third parties and system services

The game uses the Godot Engine runtime and Apple system services needed to run the app and store local files. The bundled privacy manifest declares required-reason APIs used by the runtime, including file timestamps, system boot time, and disk-space checks. These APIs are not used to build a profile or track you.

Retention and deletion

Local progress remains on your device until you delete it in the app where a supported reset action is available, or remove the app from the device. Deleting the app removes its local container according to iOS behavior. There is no cloud copy to request or delete.

Children

The current build does not knowingly collect personal information from anyone, including children.

Changes to this policy

We may update this policy when the game or its data practices change. The effective date above will be updated with each revision.
